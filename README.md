This is an online quiz game built to explain and visualise the benefits of
GraphRAG.

## Projects

- `frontend/` contains the React and TypeScript Vite application.
- `backend/` contains the Java 21 and Spring Boot API.
- `docs/` contains the product, architecture, database, UI and roadmap
  documentation.

The planned REST endpoints and JSON payloads are documented in
[`docs/api.md`](docs/api.md).

See each application's README for local development commands.
